# 观复文明 · 野史戏谈 · 第一册（史书放映 · 最终版）

重建于"过去"，不见于"未来"——我们的史诗只写在"现在"：当下，如愿如常。

## 这是什么

一部以"史书"为形态的二十幕动态叙事页：从书架上取下一本《观复文明·野史戏谈·第一册》，翻开、展开，以柴尔德"城市革命"十条为基石，讲述星际废土上哲人王文明从大寂灭到制度重建的完整设定。无构建、无依赖、离线可用，适配手机/平板/电脑。

## 打开方式

直接用浏览器打开 `index.html` 即可。

## 内容与交互

- **开场**：书架上一本书缓慢飞至桌前，封面展开，翻页放大进入卷首；点击"进入文明"开启正卷
- **正卷**：二十幕史书（卷首 → 三时代 → 环日城邦 → 大寂灭 → 制度核心 → 王权论 → 时间宗教 → 十条对照 → 六裂缝 → 王的一天 → 复归祭 → 观止院簿 → 故事的入口 → 邻国 → 第一炉火·上/中/终 → 第二炉火 → 终章 → 卷末·跋）
- **推进**：点击空白 / "下一幕" / 空格·回车·方向键 / 触屏左右滑动；连点自动排队累进
- **目次**：左上"目次"打开二十幕索引，点击跳转，自动定位当前幕
- **故事卷**：幕中"手抄本"篇章点击即展卷（含两幅蚀刻版画插图）；"故事的入口"是九个故事方块；键盘 ↑↓ 或 PageUp/Down 卷内滚动，Esc 关闭
- **翻阅全书**：卷末"合上此书"收卷后，结束卡片上可"翻阅全书"（完整设定全文 389 段）或"重新展卷"
- **背景**：3D 宇宙奇观贯穿全卷——太阳与三重星环、行星轨道、银河旋臂星云、流星带、深空之眼、超远尘埃环、漂浮残页；随幕切换明暗呼吸；系统开启"减弱动态"时自动降速而非禁用
- **全屏**：左下角透明按钮一键全屏

## 部署到 GitHub Pages

任选其一：

```bash
# 方式一：命令行（已登录 gh）
cd guanfu-demo
git init && git add . && git commit -m "观复文明史书 最终版"
gh repo create guanfu-civilization --public --source=. --push
# 然后：仓库 Settings → Pages → 部署分支 main / 根目录

# 方式二：直接推送已有仓库
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
# 同样在 Settings → Pages 开启，即可通过 https://<用户名>.github.io/<仓库名>/ 访问
```

> 提示：`assets/vendor/` 与 `assets/img/` 必须随站上传，页面字体与插图依赖它们；GitHub Pages 站点地址发布后可直接分享链接展示。

## 设定要点（不可篡改）

- 新纪元只允许唯一"哲人王"，自王之下各司其职，没有对王的约束——这是文明重建初级阶段主动制造的制度性缺陷，用以使其他缺陷最小化
- 王的意志即法：王首先做到了能托举整个文明，他才是王；不是因为文明成员承认他才是王
- 刻意不看哲人王的存在时，这个文明表现得其实是完美的
- 卷末跋文：我们的文明，重建于"过去"，不见于"未来"，我们的史诗只写在"现在"——当下，如愿如常
